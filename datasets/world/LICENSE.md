# License — world (Gapminder via vega-datasets)

This example dataset's source file (`source/gapminder.json`) is copied
verbatim from the **vega-datasets** npm package
(`https://cdn.jsdelivr.net/npm/vega-datasets@2/data/gapminder.json`), which
bundles a curated extract of the **Gapminder Foundation**'s country
statistics (population, life expectancy, fertility) for teaching/demo use.

`vega-datasets`' own `package.json` declares its license as `BSD-3-Clause`
(checked against the published npm registry metadata for `vega-datasets@2`;
the package's git repository carries no separate top-level `LICENSE` file at
the time this dataset was built). The standard BSD 3-Clause text is
reproduced below, as the license requires for redistribution.

Only the raw `gapminder.json` values are used here — no vega-datasets code
is vendored.
