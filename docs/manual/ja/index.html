Asterism ユーザーマニュアル

Asterism は、研究データを「つながったデータ」にする道具です。チャットで知りたいことを話すと、AI が答えに要る知識を知識グラフに足し、あなたが確かめて 承認で確定します。表や文書を添えると、データも同じ流れで公開できます。公開したデータには、ふつうの言葉で質問でき、答えには出どころが付きます。公開するまで、データは誰にも見えません。

画面は 3 領域だけです。

領域役割
左: チャットの一覧話（1 つの知りたいこと）を溜めておく。たためる
中央: チャット話す・質問する・表を添える（クリップ）・承認で確定する
右: 知識グラフ・問い用語（青）とデータの種類（緑）の全体の図と、押した点のデータの表。上のタブで承認した問いの一覧にも切り替わる。薄い＝提案、濃い＝承認済み

たとえば「どの食材をどの店で買うのが安い？」や「じゃがいもが一番安い店は？」が、そのまま話の始まりになります。狭い画面（375px）では、チャットと知識グラフと問いがタブになります。
