# 三つ星の A と紺色によるブランドの統一

日付: 2026-11-10。状態: 採用（製品への反映とリリース準備）。

## 決定

利用者が採用した左右対称の三つ星 A マークと、ロゴタイプ比較の 01 を使う。
有機的な曲線で星同士をつなぎ、星・関係・A が一つの記号として読める形を保つ。
元画像の輪郭を SVG として保存し、別のフォントや新しい描画で置き換えない。

色は利用者の指定「アプリとマニュアルをロゴの紺色に合わせる」に従い、
`#002869` を共通の主色にする。背景・罫線・本文も紺色に調和する値へ変更する。
暗いマニュアルでは同系色 `#b7ccff` で可読性を保つ。
2026-11-10 追補: 前回の「PROV のデータ/処理と成功の意味色は維持する」という決定を、
利用者の「全体を一貫させ、緑のノードも紺へ」という指定により改訂する。
役割は維持し、データを紺 `#002869`、処理を青灰 `#526f9a`、成功を紺系 `#254b70` に揃える。
警告・エラーは専用の注意色を維持する。

グラフは色だけに依存せず、用語を輪郭円、データの種類を塗り円、データセットを中心点付き輪郭円にする。
提案には淡さと「(提案)」ラベルを併用し、値のつながりは最大 8 種類の番号を点と凡例で共有する。
主画面は濃紺の作業面と 3 領域を基本とし、ロゴはマーク 26px＋ロゴタイプ高さ 14.5px に抑える。
左右の上部 64px、一覧幅 220px（折りたたみ 56px）、操作高 36px（アイコン 32px・粗いポインター 44px）、
本文 14–15px・補足 12px 以上、8 / 16 / 24px の余白を共通基準とする。
視覚的序列・近接・整列・反復、および色以外の手がかりと文字コントラストの根拠は
[UI ガイドライン](../design/ui-guidelines.md#判断の根拠) にまとめる。

## 適用と維持

2026-11-10 のリリース依頼に合わせ、比較していた「濃紺の面・青白い情報・淡い金の操作」を製品に採用する。
初回はダーク表示とし、設定上部の「外観」でダーク／ライトを切り替える。選択は端末のブラウザに保存する。
保存が使えない場合も切り替えは動作し、次回起動はダークに戻る。OS の外観には自動追従しない。
読み込みの最初に保存設定を適用し、グラフは表示位置・拡大率・選択を保って色だけを更新する。

| 役割 | ダーク | ライト |
|---|---|---|
| ブランド・データ | 青白 `#b7ccff` | 紺 `#002869` |
| 主要操作・現在地 | 淡い金 `#ebc86e` | 紺 `#002869` |
| 作業面 | 濃紺 `#111d30` | 白 `#ffffff` |
| 警告・エラー | 橙・赤＋状態の文言 | 橙・赤＋状態の文言 |

金の塗りは主ボタン、現在地は文字と下線、補助操作は通常の面とする。
ロゴの正本色は紺のまま維持し、操作色とは分離する。グラフに金色の星や発光を足さない。
利用者の「夜空」はダーク表示の意図だったため、星の選択マーカー案は撤回済み。
比較入口 `ui/previews/` は検討の履歴として残し、通常入口を製品の正とする。

マニュアルもダークを既定とし、目次上部の「外観」でライトへ切り替えられる。
アプリとマニュアルは別の保存領域なので、それぞれの選択を記憶する。起動画面は濃紺と淡い金を用いる。

| 正本 | 反映先 |
|---|---|
| `brand/source/*.svg`、`brand/colors.json` | UI、favicon、起動画面、OS アイコン、マニュアル |
| `ui/src/index.css`、`ui/src/appearance.css` | ライトの基準とダークの共通色トークン |
| `manual/site/style.css` | マニュアルの明暗配色 |

`scripts/sync_brand.py --check` とマニュアルの生成物検査で、複数の掲載先の不一致を検出する。
手順と元画像の由来は [brand/README.md](../../brand/README.md) に置く。
ブランド変更によって名称、IRI、データ処理、操作手順を変更しない。
リリースの実施状況は [ROADMAP](../ROADMAP.md) と GitHub Releases に記録する。
