# 三つ星の A と紺色によるブランドの統一

日付: 2026-11-10。状態: 採用（ローカル実装済み、公開前）。

## 決定

利用者が採用した左右対称の三つ星 A マークと、ロゴタイプ比較の 01 を使う。
有機的な曲線で星同士をつなぎ、星・関係・A が一つの記号として読める形を保つ。
元画像の輪郭を SVG として保存し、別のフォントや新しい描画で置き換えない。

色は利用者の指定「アプリとマニュアルをロゴの紺色に合わせる」に従い、
`#002869` を共通の主色にする。背景・罫線・本文も紺色に調和する値へ変更する。
暗いマニュアルでは同系色 `#b7ccff` で可読性を保つ。
PROV のデータ/処理と成功/警告/エラーの意味色は維持する。

## 適用と維持

| 正本 | 反映先 |
|---|---|
| `brand/source/*.svg`、`brand/colors.json` | UI、favicon、起動画面、OS アイコン、マニュアル |
| `ui/src/index.css` | UI の共通色トークン |
| `manual/site/style.css` | マニュアルの明暗配色 |

`scripts/sync_brand.py --check` とマニュアルの生成物検査で、複数の掲載先の不一致を検出する。
手順と元画像の由来は [brand/README.md](../../brand/README.md) に置く。
ブランド変更によって名称、IRI、データ処理、操作手順を変更しない。
マージ・公開・配布版の更新は、このローカル実装とは別の操作とする。
