The identifier works in SPARQL against the store that holds the dataset — your Asterism instance's SPARQL（開発者向け） view, the API's /api/sparql, or the in-browser demo for the published subset:

DESCRIBE <…>

Answers produced by Asterism's verified tools cite these IRIs so the exact evidence row can be re-fetched, compared, and audited — identifier stability is the point; HTTP resolution is a convenience layered on top.

Instance IRIs on this static site are identifiers only (see the namespace note): serving a description per IRI needs a live SPARQL service behind this domain, which a static GitHub Pages site cannot provide. A running Asterism answers it at /describe?iri=… (Turtle for machines, HTML for humans).
