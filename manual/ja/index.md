# Asterism ユーザーマニュアル

Asterism は、研究データを「つながったデータ」にする道具です。チャットで知りたいことを話すと、AI が答えに要る知識を図に足し、
あなたが確かめて 確認で確定します。表や文書を添えると、データも同じ流れで公開できます。
公開したデータには、ふつうの言葉で質問でき、答えには出どころが付きます。公開するまで、データは誰にも見えません。

![最初の画面。左にチャットの一覧、中にチャット、右に地図](../screenshots/home-empty.png)

画面は 3 領域だけです。

| 領域 | 役割 |
|---|---|
| 左: チャットの一覧 | 話（1 つの知りたいこと）を溜めておく。たためる |
| 中央: チャット | 話す・質問する・表を添える（クリップ）・確認で確定する |
| 右: 地図 | 用語（青）とデータの種類（緑）の全体の地図と、このチャットの図の図。薄い＝提案、濃い＝確認済み |

たとえば熱電材料なら「ZT が最も高い試料の組成は？」、献立なら「にんじんを使うレシピは？」が、そのまま話の始まりになります。
狭い画面（375px）では、チャットと図がタブになります。
