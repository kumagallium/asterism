# 全体のデザイン調整（2026-11-10）

## 判断と変更

| 原則 | 変更 | 意図 |
|---|---|---|
| 視覚的な序列 | マーク34→26px、文字19→14.5px。空状態は見出し20pxと本文14px | ロゴを画面の署名にし、内容と次の操作を読みやすくする |
| 近接と整列 | ナビ220px、ヘッダー64px、余白8/16/24px | 関連する情報をまとめ、領域間で基準位置を揃える |
| 反復 | 操作36px・アイコン32px、本文14〜15px・補足12px | チャットと設定で同じ操作密度にする |
| 色の役割 | 紺を主要操作、青灰色を補助、白を作業面にする | グラフ・フォーム・ナビで競合する強調を減らす |
| 色以外の手がかり | 用語○、種類●、データセット⊙。詳細グラフは種類番号①〜⑧ | 色だけで種類を判別しなくてよいようにする |
| 図と地 | ノード名の直下を紙色で抜き、線が文字を横切らないようにする | グラフの関係と名前を読める状態にする |

色以外の形や文字を併用する根拠は [W3C Use of Color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)。
通常文字の確認基準は [W3C Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。
この記録は画面全体の WCAG 適合認証を意味しない。

## 色の測定

CSS の RGB 値から相対輝度を計算した。

| 前景 / 背景 | コントラスト比 |
|---|---:|
| 主色 `#002869` / 白 | 13.93:1 |
| 補助文字 `#60728a` / 補助面 `#f7f9fc` | 4.66:1 |
| 用語 `#526f9a` / グラフ面 `#fbfcfe` | 4.99:1 |
| 通常線 `#687e9b` / グラフ面 | 4.05:1 |
| 提案の点・線 `#8193ab` / グラフ面 | 3.06:1 |

提案の本文を opacity で薄くする規則も、読みやすい文字色・状態ラベルへ変更した。
確定済みの論文の根拠線は細くても確定色とし、線の太さと提案状態を別々に扱う。
