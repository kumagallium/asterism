# 星座らしさを選択表示に添える試作（2026-11-10）

**撤回済み**。利用者の意図はダークモードを基本にするかという配色方針だったため、星マーカーの追加は解釈違いだった。マーカーと関係線の追加強調を取り除いた。以下は試行時の記録で、現在の画面仕様ではない。

利用者の「試してみてください」に応じ、現在の白・紺の UI に小さな星の選択印を追加した。

| 表現 | 意味と範囲 |
|---|---|
| 選択した点の上に柔らかい六尖星 | 現在の選択。色は共通の紺 `#002869` |
| つながる線を 1.2 倍に強調 | 選択・hover・既存の関連点強調に伴う関係。根拠・提案の色と相対的な太さは維持 |
| 選択ラベルの白い影を除去 | 名前は紙色の下地だけで読みやすく表示 |

種類を表す ○・●・⊙、元の ID・名前・配置・件数による点の大きさ・クリック範囲を維持した。
装飾だけの点や線・発光・点滅は追加していない。星は SVG の補助レイヤーで、クリックを遮らない。
