# 濃紺ダークの配色比較（2026-11-10）

利用者の「夜空の星らしさ」は、ダークモードを既定にするかという配色方針の相談だった。
前回の選択星マーカーは解釈違いとして撤回し、画面全体の明暗を比較する試作へ修正した。

## 比較

- [濃紺のダーク案](dark.jpg)
- [現在のライト案](light.jpg)
- [ダークで点を選択](dark-selected.jpg)
- [ライトで点を選択](light-selected.jpg)
- [ダークの設定画面](settings.jpg)

濃紺の面に、明るい青白色のロゴ・ノードと控えめな関係線を置く。
ロゴの形やデータ構造、操作は同じで、星の装飾や発光は加えていない。
1280px 幅の実アプリを使い、同梱の世界の国（Gapminder）を独立した一時データ領域で表示した。
選択時のラベルは面と同色の下地を使い、暗面にも白い札が残らないようにした。

## 試作の入口と範囲

`ui/` で通常の開発サーバーを起動し、`/previews/night.html` を開く。
通常の `/` はライトのまま。試作用 CSS は `data-theme="night-preview"` が付く入口だけに適用する。
設定保存・OS の設定・製品の既定テーマは変更していない。通常の本番ビルドにも試作入口は含まれない。
主画面と設定の比較用であり、全詳細画面のダーク対応を完了したものではない。
配布・公開は行っていない。

指定した RGB 値から相対輝度比を計算した。画面全体の適合認証を意味しない。

## 確認

- 独立レビューで、試作の隔離・星の撤去・○●⊙の描画とクリック範囲の維持を確認。
- ブラウザで通常表示、点の選択、設定画面を確認。ライト側にも星マーカーが残っていない。
- マニュアルの星の説明を削除し、現在のライト画面へ画像を差し替えた。
- UI 全体は 1,136 件成功・配置計算 1 件が 5 秒の時間制限で失敗。その対象ファイルを単独で再実行し、58 件すべて成功（1.83 秒）。時間制限・配置コードは変更していない。
- マニュアル関連 33 件、型検査・ESLint・本番ビルド・生成物同期検査は成功。本番配信ファイルサイズの警告と Python の既存 timeout 設定警告 2 件は残る。
